Publish a skill

Every way of publishing opens a pull request. Checks run on it. If they pass and the skill bundles no code, it merges automatically and appears in the marketplace as Experimental within a few minutes. Skills that run code wait for a reviewer.

How to create the token
  1. Open GitHub › Fine-grained tokens › Generate new token.
  2. Repository access: Only select repositories › this catalog's repository.
  3. Permissions: Contents Read and write, Pull requests Read and write.
  4. Generate, copy, paste it above.

The token stays in this browser tab only (cleared when you close it) and is sent only to api.github.com.

The frontmatter's name and description become the plugin name and description. Need reference files or scripts too? Use “Upload files or a zip”.

Drop a skill folder, its files, or a .zip here

SKILL.md at the root, references and scripts in subfolders. Up to 100 files, 5 MB.

    Publish from a Claude Code session

    1. Add this marketplace (once)

      claude plugin marketplace add …

    2. Install the publisher

      claude plugin install publish-skill@skills-catalog

    3. In any session, point it at your skill folder

      /publish-skill:publish-skill ./path/to/my-skill

    It asks for the owner, runs the same checks as this page, and opens the pull request with the GitHub CLI. It needs git, node and a logged-in gh. Prefer doing it by hand? See Publishing a skill manually.
